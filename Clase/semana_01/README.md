## Cómo trabajar

```bash
pip install pytest
pytest -v
```

Al empezar, las pruebas fallan: eso es lo esperado. Ve completando
una función a la vez y volviendo a ejecutar `pytest` hasta que pasen todas.

## Regla del curso

No sustituyas la estructura exigida por `list`, `dict`, `set`, `deque`
o `heapq`. Sí puedes usarlas como soporte interno (por ejemplo, un
arreglo subyacente) siempre que lo justifiques en tu `plan.md`.
